# Support

For project usage and reproducible bugs, use GitHub Issues:

https://github.com/roseshayan/SpeedyBot/issues

Before opening an Issue:

1. Read `README.md` / `README_FA.md`.
2. Run `/xuidiag`, `/groupsdiag`, or `/notifydiag` when relevant.
3. Check `journalctl -u xui-bot.service -n 150 --no-pager`.
4. Remove all tokens, subscription links and private customer data from logs.
