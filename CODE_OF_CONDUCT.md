# Code of Conduct

SpeedyBot welcomes respectful technical discussion and contributions.

Please:

- be respectful and constructive;
- focus discussions on reproducible technical facts;
- avoid harassment, spam and personal attacks;
- never publish private user or deployment data;
- respect the project license and attribution.
