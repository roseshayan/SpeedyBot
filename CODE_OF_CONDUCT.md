# Code of Conduct

SpeedyBot welcomes respectful technical discussion and contributions.

Please:

- be respectful and constructive;
- focus discussions on the project and reproducible technical facts;
- avoid harassment, spam and personal attacks;
- do not publish private user information or confidential deployment data;
- respect the project license and author attribution.
