# SpeedyBot v3 — ربات فروش و مدیریت VPN برای 3x-ui / Sanaei

SpeedyBot یک ربات تلگرام فروش خودکار سرویس VPN برای پنل **3x-ui / Sanaei** است. اطلاعات فروش و کاربران در SQLite ذخیره می‌شود و ربات روی Ubuntu با systemd اجرا می‌شود.

## امکانات اصلی

### فروش و سرویس
- ساخت خودکار Client روی تمام Inboundهای فعال پنل.
- سه پلن پیش‌فرض نامحدود ۳۰ روزه:
  - ۱ کاربر — ۲۵۰٬۰۰۰ تومان — `limitIp=1`
  - ۲ کاربر — ۳۰۰٬۰۰۰ تومان — `limitIp=2`
  - ۳ کاربر — ۳۵۰٬۰۰۰ تومان — `limitIp=3`
- مدیریت کامل پلان‌ها از `/sudoadmin`: افزودن، ویرایش و فعال/غیرفعال کردن.
- تست رایگان ۱GB / ۱ روز با `limitIp=1`، فقط یک بار برای هر Telegram ID.
- تمدید همان سرویس با حفظ Subscription ID و نام Client.
- امکان تعریف بسته‌های حجم اضافه برای سرویس‌های حجمی.
- لینک Subscription، کانفیگ‌های مستقیم و QR Subscription.
- Retry و Recovery امن برای تراکنش‌های نیمه‌کاره.

### Groups در Sanaei
- خرید موفق → Group پیش‌فرض `Customers`.
- تست رایگان → Group پیش‌فرض `Trial`.
- اگر Group لازم وجود نداشته باشد، ربات آن را ایجاد می‌کند.
- هنگام Startup، سرویس‌های قدیمی صادرشده توسط ربات با Group درست همگام می‌شوند.
- `/groupsdiag` تعداد دقیق Groupهای زنده پنل و تعداد Client هر Group را نشان می‌دهد.
- همین اطلاعات از `/sudoadmin` → «👥 گروه‌های Sanaei» نیز در دسترس است.

### تجربه کاربر
- حساب کاربری و مشاهده وضعیت زنده حجم/زمان.
- تمدید سرویس از داخل حساب.
- تاریخچه ۱۵ خرید/تمدید/حجم اضافه اخیر.
- کیف پول و تاریخچه تراکنش‌ها.
- کد هدیه و کد تخفیف.
- همکاری در فروش و لینک دعوت اختصاصی.
- FAQ و راهنمای قابل ویرایش.
- احراز شماره موبایل اختیاری.
- عضویت اجباری در کانال تلگرام به‌صورت اختیاری.

### بازاریابی
- Referral / Affiliate یک‌سطحی با پورسانت قابل تنظیم.
- Cashback قابل تنظیم.
- کد تخفیف درصدی یا مبلغ ثابت با حداقل خرید، تعداد مصرف و تاریخ انقضا.
- Gift Code برای شارژ کیف پول.

### مدیریت
`/sudoadmin`

- آمار فروش، خرید جدید، تمدید و حجم اضافه.
- درآمد امروز، درآمد نقدی/کارت و فروش کیف پول.
- تعداد کاربران و Referralها.
- تعداد Clientهای آنلاین و Groupهای زنده پنل در صورت دسترس بودن API.
- مدیریت Plan و Volume Pack.
- مدیریت Groupها و Reconcile.
- مدیریت Cashback / Discount / Gift Code.
- مدیریت کیف پول کاربران.
- چند ادمین؛ `ADMIN_ID` اصلی Owner باقی می‌ماند.
- ویرایش متن خوش‌آمدگویی و FAQ.
- روش نام‌گذاری سرویس: `TelegramID + Transaction` یا Random.
- بکاپ خودکار SQLite و بکاپ دستی.
- اعلان اتمام حجم/زمان و هشدار نزدیک اتمام.

## اعلان سرویس

پیش‌فرض هر ۵ دقیقه یک بار Clientها از پنل بررسی می‌شوند:
- هشدار مصرف ۹۰٪ حجم.
- هشدار ۲۴ ساعت مانده به پایان سرویس پولی.
- هشدار ۳ ساعت مانده به پایان تست.
- اعلان یک‌باره اتمام حجم یا زمان.

دستور ادمین:

```text
/notifydiag
```

## عیب‌یابی API

```text
/xuidiag
/groupsdiag
```

API ربات با Bearer Token و endpointهای `/panel/api/*` کار می‌کند.

## نصب روی Ubuntu 24.04

```bash
git clone https://github.com/roseshayan/SpeedyBot.git /root/SpeedyBot
cd /root/SpeedyBot
chmod +x install.sh update.sh
./install.sh
```

Installer موارد زیر را درخواست می‌کند:
- Telegram Bot Token
- Telegram Admin ID
- X-UI API URL
- X-UI Web Base Path
- X-UI Bearer Token
- Subscription Server URL

## آپدیت مستقیم از GitHub

بعد از نصب اولیه:

```bash
cd /root/SpeedyBot
./update.sh
```

فقط بررسی نسخه:

```bash
./update.sh --check
```

نصب مجدد آخرین commit:

```bash
./update.sh --force
```

Updater قبل از Deploy از `.env`، دیتابیس و سورس فعلی بکاپ می‌گیرد؛ `.env` و `speedping.db` پاک نمی‌شوند و در صورت بالا نیامدن نسخه جدید Rollback انجام می‌شود.

## فایل‌های Runtime که نباید Commit شوند

`.gitignore` این موارد را نادیده می‌گیرد:
- `.env`
- `*.db`
- `.venv/`
- `backups/`

## نکات امنیتی

- API Token پنل و Bot Token را هرگز داخل GitHub قرار ندهید.
- برای کانال اجباری، ربات باید امکان `getChatMember` برای کانال موردنظر را داشته باشد.
- QR و Subscription Link حاوی اطلاعات دسترسی هستند و باید مثل رمز عبور نگهداری شوند.

## قابلیت‌هایی که فعلاً عمداً داخل این نسخه نیستند

Telegram Mini App، Web Admin Panel مستقل، چند پنل/چند درگاه پرداخت، Lottery و سیستم Reseller چندسطحی نیاز به معماری و UI جداگانه دارند و در این نسخه به‌صورت نصفه و ناامن اضافه نشده‌اند. هسته ربات برای اضافه شدن این ماژول‌ها در نسخه‌های بعدی آماده شده است.
