# ربات تلگرام فروش خودکار X-UI / سنائی

این پروژه یک ربات تلگرام برای فروش خودکار سرویس‌های X-UI / پنل سنائی 3.3.0 است.  
فرآیند کار به این شکل است:

1. نمایش پلن‌ها به کاربر
2. دریافت عکس فیش واریزی
3. بررسی دستی توسط ادمین
4. ساخت خودکار اکانت در پنل
5. ارسال لینک سابسکریپشن و کانفیگ مستقیم برای کاربر

داده‌های ربات در **SQLite** ذخیره می‌شوند و اجرای آن با **systemd** روی اوبنتو انجام می‌شود.

## محیط تست

- Ubuntu 24.04
- پنل Sanaei 3.3.0
- Python 3
- `pyTelegramBotAPI`
- `requests`

## امکانات ربات

- نمایش منوی ساده برای کاربران
- نمایش اطلاعات کارت و حساب واریز
- دریافت عکس فیش پرداخت
- ارسال فیش برای ادمین
- تایید یا رد پرداخت توسط ادمین
- ساخت خودکار کلاینت در پنل X-UI پس از تایید
- تولید:
  - لینک سابسکریپشن
  - لینک‌های کانفیگ مستقیم
- سیستم پشتیبانی داخلی
- پنل مدیریت با دستور `/sudoadmin`

## فایل‌های پروژه

- `main.py` — منطق ربات، دیتابیس SQLite، اتصال به API پنل

## پیش‌نیازها

شما به این موارد نیاز دارید:

- توکن ربات تلگرام از BotFather
- آیدی عددی ادمین تلگرام
- توکن ادمین پنل X-UI / سنائی
- آدرس API پنل
- بیس‌پث امنیتی پنل
- آدرس سرور سابسکریپشن برای لینک‌های `/sub/...`

### متغیرهای محیطی

ربات این متغیرها را از محیط اجرا می‌خواند:

- `BOT_TOKEN`
- `ADMIN_ID`
- `XUI_API_URL`
- `XUI_BASE_PATH`
- `XUI_BEARER_TOKEN`
- `XUI_SUB_SERVER_URL`

نمونه:

```bash
BOT_TOKEN=123456:ABCDEF...
ADMIN_ID=123456789
XUI_API_URL=http://127.0.0.1:2053
XUI_BASE_PATH=/
XUI_BEARER_TOKEN=your-panel-bearer-token
XUI_SUB_SERVER_URL=https://sub.example.com:2096
```

### نکات مهم درباره مقادیر پنل

- `XUI_API_URL` باید همراه با پروتکل و پورت باشد.
- `XUI_BASE_PATH` باید دقیقاً با مسیر امنیتی پنل یکی باشد.
  - اگر پنل مسیر امنیتی ندارد، از `/` استفاده کنید
  - اگر دارد، چیزی شبیه `/pKPl2UQ2sKTDnSWXb0` وارد کنید
- `XUI_SUB_SERVER_URL` برای ساخت لینک‌هایی مثل زیر استفاده می‌شود:
  `https://sub.example.com:2096/sub/<id>`

## نصب روی Ubuntu 24.04

### روش اول: نصب خودکار

فایل‌های پروژه را روی سرور قرار دهید و این دستور را اجرا کنید:

```bash
chmod +x install.sh
sudo ./install.sh
```

اسکریپت نصب از شما این اطلاعات را می‌پرسد:

- توکن ربات
- آیدی ادمین
- آدرس API پنل
- بیس‌پث پنل
- توکن Bearer پنل
- آدرس سرور سابسکریپشن

سپس این کارها را انجام می‌دهد:

- نصب پکیج‌های پایتون
- ساخت دایرکتوری `/root/xui-shop-bot`
- کپی کردن `main.py`
- ساخت virtualenv
- نصب وابستگی‌ها
- ساخت سرویس `systemd` با نام `xui-bot.service`
- فعال و اجرا کردن سرویس

### روش دوم: نصب دستی

پکیج‌های سیستم را نصب کنید:

```bash
sudo apt update
sudo apt install -y python3 python3-pip python3-venv
```

پوشه کاری را بسازید:

```bash
sudo mkdir -p /root/xui-shop-bot
sudo cp main.py /root/xui-shop-bot/main.py
cd /root/xui-shop-bot
```

محیط مجازی و وابستگی‌ها را نصب کنید:

```bash
python3 -m venv .venv
./.venv/bin/pip install --upgrade pip
./.venv/bin/pip install pyTelegramBotAPI requests
```

فایل سرویس systemd را بسازید:

```bash
sudo nano /etc/systemd/system/xui-bot.service
```

و این محتوا را داخل آن قرار دهید:

```ini
[Unit]
Description=X-UI Telegram Shop Bot Service
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/xui-shop-bot
ExecStart=/root/xui-shop-bot/.venv/bin/python3 /root/xui-shop-bot/main.py
Restart=always
RestartSec=5
Environment=BOT_TOKEN=YOUR_BOT_TOKEN
Environment=ADMIN_ID=YOUR_ADMIN_ID
Environment=XUI_API_URL=YOUR_XUI_API_URL
Environment=XUI_BASE_PATH=YOUR_XUI_BASE_PATH
Environment=XUI_BEARER_TOKEN=YOUR_BEARER_TOKEN
Environment=XUI_SUB_SERVER_URL=YOUR_SUB_SERVER_URL

[Install]
WantedBy=multi-user.target
```

سرویس را فعال و اجرا کنید:

```bash
sudo systemctl daemon-reload
sudo systemctl enable xui-bot.service
sudo systemctl start xui-bot.service
```

بررسی وضعیت و لاگ:

```bash
sudo systemctl status xui-bot.service
sudo journalctl -u xui-bot.service -f
```

## تنظیمات اولیه بعد از اجرا

بعد از بالا آمدن ربات، در تلگرام `/start` بفرستید.

ربات فایل دیتابیس محلی زیر را می‌سازد:

- `speedping.db`

در اجرای اول، اطلاعات پیش‌فرض واریز داخل دیتابیس ثبت می‌شود:

- شماره کارت
- نام صاحب حساب
- نام بانک

حتماً قبل از دریافت پرداخت واقعی، این اطلاعات را از پنل مدیریت تغییر دهید.

## روند کار کاربر

### 1) ورود به ربات
کاربر `/start` می‌زند و منوی اصلی را می‌بیند.

### 2) انتخاب پلن
ربات پلن‌های تعریف‌شده در `PLANS` داخل `main.py` را نمایش می‌دهد.

پلن پیش‌فرض فعلی:

```python
1: {"name": "پلان نامحدود (یک‌ماهه)", "price": 300000, "volume": 0, "days": 30}
```

### 3) پرداخت دستی
ربات اطلاعات کارت و بانک را از دیتابیس SQLite می‌خواند و نشان می‌دهد.

### 4) ارسال فیش پرداخت
کاربر باید **عکس** فیش را به صورت Reply به همان پیام ارسال کند.

اگر متن بفرستد و عکس نفرستد، ربات آن را رد می‌کند.

### 5) بررسی توسط ادمین
فیش برای ادمین فوروارد می‌شود و دو دکمه دارد:

- تایید پرداخت
- رد فیش

### 6) ساخت خودکار سرویس
وقتی ادمین فیش را تایید کند:

- برای کاربر یک ایمیل/شناسه به شکل زیر ساخته می‌شود:
  `speedping_<telegram_id>_<transaction_id>`
- ربات همه اینباندهای فعال را از پنل می‌خواند
- کلاینت جدید روی آن اینباندها ساخته می‌شود
- لینک‌های اتصال گرفته می‌شوند
- برای کاربر ارسال می‌شود:
  - لینک سابسکریپشن
  - لینک‌های مستقیم

## ارتباط ربات با پنل سنائی / X-UI

ربات از API پنل با توکن Bearer استفاده می‌کند.

اندپوینت‌های اصلی که در کد استفاده شده‌اند:

- `GET /panel/api/server/status`
- `GET /panel/api/inbounds/list`
- `POST /panel/api/clients/add`
- `GET /panel/api/clients/get/{email}`
- `GET /panel/api/clients/traffic/{email}`
- `GET /panel/api/clients/links/{email}`
- `POST /panel/api/clients/del/{email}?keepTraffic=0`

پنل باید این مسیرها را دقیقاً همان‌طور که در پروژه استفاده شده پشتیبانی کند.

## تغییر قیمت‌ها و پلن‌ها

همه پلن‌ها داخل دیکشنری `PLANS` در فایل `main.py` تعریف شده‌اند.

برای اضافه کردن پلن جدید، همان دیکشنری را ویرایش کنید و سرویس را ریستارت کنید.

نمونه:

```python
PLANS = {
    1: {"name": "پلان نامحدود (یک‌ماهه)", "price": 300000, "volume": 0, "days": 30},
    2: {"name": "20 گیگ / 30 روز", "price": 250000, "volume": 20, "days": 30},
}
```

نکات:

- `price` بر حسب تومان است
- `volume = 0` یعنی حجم نامحدود
- `days` زمان انقضا را مشخص می‌کند
- آمار درآمد در کد فعلی بر اساس قیمت همان پلن محاسبه می‌شود

## تغییر اطلاعات کارت

از طریق `/sudoadmin` وارد پنل مدیریت شوید و بخش **تنظیمات حساب واریز** را باز کنید.

قابل تغییر است:

- شماره کارت
- نام صاحب حساب
- نام بانک

این اطلاعات در SQLite ذخیره می‌شوند و در پیام‌ها به‌صورت داینامیک نمایش داده می‌شوند.

## عیب‌یابی

### ربات بالا نمی‌آید
این موارد را بررسی کنید:

- `BOT_TOKEN` درست است
- `ADMIN_ID` عددی است
- virtualenv ساخته شده
- بسته‌های `pyTelegramBotAPI` و `requests` نصب شده‌اند

### ربات بالا می‌آید ولی ارتباط با پنل خطا می‌دهد
بررسی کنید:

- `XUI_API_URL` از روی سرور قابل دسترسی است
- `XUI_BASE_PATH` درست است
- `XUI_BEARER_TOKEN` معتبر است
- توکن پنل اجازه استفاده از API را دارد
- اندپوینت‌ها با رفتار Sanaei 3.3.0 سازگار هستند

### بعد از تایید، کاربر کانفیگ دریافت نمی‌کند
بررسی کنید:

- اینباند فعال در پنل وجود دارد
- درخواست ساخت کلاینت موفق بوده است
- `XUI_SUB_SERVER_URL` درست است
- سرور سابسکریپشن در دسترس است

### پشتیبانی یا فوروارد پیام کار نمی‌کند
بررسی کنید:

- آیدی ادمین درست است
- ادمین همان اکانتی است که در `ADMIN_ID` ثبت شده
- ربات محدودیت تلگرام نخورده باشد

## توصیه‌های امنیتی

- توکن API پنل را عمومی نکنید.
- ربات را فقط روی سرور مطمئن اجرا کنید.
- مقادیر پیش‌فرض کارت را فوراً عوض کنید.
- برای پنل از مسیر امنیتی قوی استفاده کنید.
- فایل `speedping.db` را مرتب بکاپ بگیرید.
- دسترسی‌های فایروال سرور را محدود کنید.
