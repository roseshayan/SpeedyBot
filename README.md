# 🚀 ربات تلگرام فروش خودکار اکانت X-UI (Sanaei v3.3.0)

این ربات به مدیران سرورهای وی‌پ‌ان اجازه می‌دهد تا فرآیند فروش، دریافت فیش واریزی، تایید توسط مدیریت و صدور کانفیگ‌های مستقیم و لینک‌های سابسکریپشن (پورت ۲۰۹۶) را کاملاً خودکار و بر بستر دیتابیس SQLite مدیریت کنند.

## ✨ قابلیت‌ها
- نمایش کارت بانکی داینامیک و دریافت فیش از کاربر
- چت پشتیبانی دوطرفه درون‌برنامه‌ای (ریپلاي ادمین)
- پنل مدیریت پیشرفته (`/sudoadmin`) همراه با آمار زنده سرور و آمار فروش به تومان
- استخراج کاملاً داینامیک اینباندهای فعال و اتصال کلاینت جدید به همه آن‌ها

## 🛠 نیازمندی‌ها
- این ربات منحصراً بر روی **پنل ۳x-ui نسخه v3.3.0 (ثنایی)** تست و بهینه‌سازی شده است.
- فعال بودن API Token در بخش `Settings -> Security -> API Token` پنل.
